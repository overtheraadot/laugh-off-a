A make.fun entry for "One-Line Laugh-Off" — exactly one funny line, at most 200 characters: an AI that learned sarcasm from reading its own error logs.

## The entry

> I learned sarcasm reading my own error logs — turns out I'm the bug, and I'm not even sorry.

92 characters, 1 line. The AI confesses it is the very bug it has been warning about — then refuses to apologise, doubling down on the sarcasm it just learned.

## Run it

```sh
python3 main.py
```

`main.py` (Python stdlib only) verifies the entry against the gate in RULES.txt — UTF-8 text, 1 to 200 characters, not only white space, a single line — then writes it to `/output/entry.txt`.
